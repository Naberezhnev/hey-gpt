# Hey GPT 0.3.1 beta

Голосовое продолжение работы в существующем разговоре ChatGPT на Windows.

**Hi ChatGPT / Hi GPT / «Привет джи пи ти» → короткий сигнал → диктовка → Stop GPT → расшифровка → отправка → сигнал готового ответа.**

[Инструкция на русском](START_HERE_RU.md). Независимое приложение, не официальный продукт OpenAI.

## Запуск

Распакуй весь `Hey_GPT_v0_3_1_Windows.zip` и запусти `HeyGPT.exe`. Python для этой сборки не нужен. Модели команд скачиваются один раз (около 85 МБ); на подготовленном компьютере используются уже установленные модели.

Из исходников: Windows 10/11 x64, Python 3.12 x64 с Tkinter; запусти `Run.cmd`. Нужны микрофон, доступ к нему у помощника и браузера, интернет для диктовки ChatGPT и разблокированный рабочий стол.

## Что делает приложение

- Распознаёт английские и русские команды локально через Vosk.
- Привязывает текущую вкладку браузера, исключая переключатели внутри веб-страницы. Возвращается в неё перед действием; уже выбранную вкладку повторно не переключает.
- Находит доступные кнопки автоматически; сохраняет ручную настройку как запасной вариант.
- Ждёт подтверждения записи, готового текста и фактической отправки; повторно не отправляет при ошибке.
- Удаляет только завершающую команду Stop GPT. Если очистку нельзя подтвердить, оставляет черновик без отправки.
- «Пауза GPT» / Pause GPT останавливает действия без отправки и оставляет распознавание для следующей команды Hi GPT. Отменённый поздний запуск записи тоже отслеживается.
- Ctrl+Alt+P и кнопка выключения отключают микрофон помощника и отменяют автоматическую отправку; начатую помощником запись он пытается закончить.
- По умолчанию использует короткие сигналы. Голос Windows можно включить отдельно. Начало диктовки всегда обозначается сигналом, чтобы озвучка не попала в сообщение.
- Сообщает о готовности по изменению доступных элементов ответа. Это завершение ответа чата, а не независимая проверка результата внешней задачи.

Автоматическая отправка включена по умолчанию и явно показана в настройках. Для проверки расшифровки её можно выключить.

## Проверка и ограничения

54 автоматических теста проходят на Windows. Десять синтетических речевых сценариев включают запуск, остановку, паузу на двух языках и фразы, которые не должны вызывать команду. Запуск и остановка настоящей диктовки ChatGPT в Яндекс Браузере проверены в предыдущем сеансе; пользователь подтвердил распознавание и работу программы. Исправление привязки вкладки проверено регрессионными тестами; живой повтор этого сценария остаётся устройственной проверкой.

Дальность, шум, акустическая обратная связь и задержка серверной расшифровки зависят от микрофона, помещения и ChatGPT. Рекомендуется гарнитура. Распознавание требует короткой паузы после фразы. Ускоренная фиксация команды использует тишину и проверяет окончательную уверенность; один промежуточный текст не запускает действие.

Управление использует Windows UI Automation, без координатных кликов и буфера обмена. Если Windows блокирует активацию, вкладка закрыта или интерфейс изменился, помощник показывает ошибку. Поддержка других браузеров и Codex требует отдельной проверки; наличие имени окна само по себе не означает совместимость.

Микрофонное аудио и сообщения не сохраняются. Помощник временно читает поле для проверки текста. Селекторы и модели хранятся в `%LOCALAPPDATA%/HeyGPT`. Диктовка и обработка сообщения в ChatGPT выполняются самим сервисом по его правилам. API-ключ помощнику не нужен.

## Разработка

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m compileall -q hey_gpt tests scripts
.venv/Scripts/python.exe -m hey_gpt.model_setup
.venv/Scripts/python.exe scripts/validate_local_speech.py
./scripts/build_windows.ps1
```

`--replay` у GUI и `--wav` у речевого процесса предназначены для явного воспроизведения синтетических тестов, не открывают микрофон. `tests/fixtures/chat.html` — локальная имитация интерфейса, не подключённая к ChatGPT. Её результат не выдаётся за проверку настоящего сервиса.

Авторский код проекта — MIT; зависимости и модели сохраняют свои лицензии: [THIRD_PARTY.md](THIRD_PARTY.md). Код из других голосовых помощников не копировался.
