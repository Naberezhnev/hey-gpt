# Hey GPT 0.4.0 beta

Голосовое продолжение работы в существующем разговоре ChatGPT на Windows.

**Hi ChatGPT / Hi GPT / «Привет джи пи ти» → короткий сигнал → диктовка → Stop GPT → расшифровка → отправка → сигнал готового ответа.**

[Инструкция на русском](START_HERE_RU.md). Независимое приложение, не официальный продукт OpenAI.

## Модуль Codex

Дополнительно доступен **Hey GPT for Codex 0.1.0 beta.2** — локальный Windows-плагин без отдельного окна. Сборка: `artifacts/Hey_GPT_Codex_Plugin_v0_1_0_Windows.zip`; установка через `Install.cmd`, затем доверие обработчикам Codex и явное включение в выбранной задаче. [Инструкция плагина](plugins/hey-gpt-codex/README_RU.md), [архитектура и границы проверки](docs/CODEX_PLUGIN.md). Для GitHub-исходников сначала нужна сборка runtime; устанавливать переносимый исходный каталог напрямую на Codex 0.159.2 не следует.

Плагин получает ответ непосредственно из обработчика Stop и возвращает следующую локально распознанную реплику в ту же задачу. Ожидание — до 58 минут; во время него Codex может показывать работающий обработчик. Постоянный голосовой запуск нового хода из холодного, завершённого состояния официального приложения пока не реализован. Плагин не требует API-ключа и не использует кнопки браузера.

Общий набор проверок приложения и модуля — 112 автоматических тестов; отдельно проверены два последовательных синтетических голосовых цикла нового модуля через настоящие Vosk-модели и запуск stdio MCP с аутентифицированным Windows IPC. Полный живой цикл внутри официального интерфейса Codex остаётся аппаратной приёмкой после доверия обработчикам.

## Запуск

Распакуй весь `Hey_GPT_v0_4_0_Windows.zip` и запусти `HeyGPT.exe`. Python для этой сборки не нужен. Модели команд скачиваются один раз (около 85 МБ); на подготовленном компьютере используются уже установленные модели.

Из исходников: Windows 10/11 x64, Python 3.12 x64 с Tkinter; запусти `Run.cmd`. Нужны микрофон, доступ к нему у помощника и браузера, интернет для диктовки ChatGPT и разблокированный рабочий стол.

## Что делает приложение

- Распознаёт английские и русские команды локально через Vosk.
- Привязывает текущую вкладку браузера, исключая переключатели внутри веб-страницы. Возвращается в неё перед действием; уже выбранную вкладку повторно не переключает.
- Находит доступные кнопки автоматически; сохраняет ручную настройку как запасной вариант.
- Ждёт подтверждения записи, готового текста и фактической отправки; повторно не отправляет при ошибке.
- Удаляет только завершающую команду Stop GPT. Если очистку нельзя подтвердить, оставляет черновик без отправки.
- «Пауза GPT» / Pause GPT останавливает действия без отправки и оставляет распознавание для следующей команды Hi GPT. Отменённый поздний запуск записи тоже отслеживается.
- Ctrl+Alt+P и кнопка выключения отключают микрофон помощника и отменяют автоматическую отправку; начатую помощником запись он пытается закончить.
- По умолчанию использует короткие сигналы. Голос Windows можно включить отдельно. Начало диктовки всегда обозначается сигналом, чтобы озвучка не попала в сообщение.
- Сообщает о готовности по изменению доступных элементов ответа. Это завершение ответа чата, а не независимая проверка результата внешней задачи.
- При включённой функции читает краткую сводку и вопросы с вариантами ответа. Просьба написать сводку добавляется к сообщениям; отдельного API-запроса нет. Если GPT не добавил раздел, приложение читает явно обозначенный фрагмент ответа и найденные вопросы.
- «Повтори» / Repeat воспроизводит последнюю озвучку из памяти. Для ответа на вопрос снова вызови Hi GPT и закончи Stop GPT — ответ уйдёт в тот же разговор.
- На время озвучки приостанавливает распознавание команд и отбрасывает накопленное аудио. Ctrl+Alt+P останавливает звук и микрофон. Голос выбирается из установленных голосов Windows.

Автоматическая отправка включена по умолчанию и явно показана в настройках. Для проверки расшифровки её можно выключить.

## Проверка и ограничения

86 автоматических теста проходят на Windows. Двенадцать синтетических речевых сценариев включают запуск, остановку, паузу и повтор на двух языках, а также фразы, которые не должны вызывать команду. Реальное чтение последнего ответа через доступность проверено на открытом окне ChatGPT; текст сообщения при проверке не сохранялся. Синтез сводки и двух вопросов проверен настоящим SAPI в синтетический WAV. Запуск и остановка настоящей диктовки ChatGPT в Яндекс Браузере проверены в предыдущем сеансе. Полный живой цикл с озвучкой и голосовым ответом остаётся устройственной проверкой.

Дальность, шум, акустическая обратная связь и задержка серверной расшифровки зависят от микрофона, помещения и ChatGPT. Рекомендуется гарнитура. Распознавание требует короткой паузы после фразы. Ускоренная фиксация команды использует тишину и проверяет окончательную уверенность; один промежуточный текст не запускает действие.

Управление использует Windows UI Automation, без координатных кликов и буфера обмена. Если Windows блокирует активацию, вкладка закрыта или интерфейс изменился, помощник показывает ошибку. Поддержка других браузеров и Codex требует отдельной проверки; наличие имени окна само по себе не означает совместимость.

Микрофонное аудио и сообщения не сохраняются. Помощник временно читает поле для проверки текста и последний ответ для озвучки. Последняя сводка хранится только в памяти до закрытия приложения или смены привязанного чата. Селекторы, настройки голоса и модели хранятся в `%LOCALAPPDATA%/HeyGPT`. Диктовка и обработка сообщения в ChatGPT выполняются самим сервисом по его правилам. API-ключ помощнику не нужен.

Функцию озвучки включи в **Настройки → Краткая сводка и вопросы**. Перед первым использованием нажми **Проверить чтение последнего ответа**. Обычные вопросы из текста поддерживаются; отдельные диалоги разрешений и формы Codex этой версией не заполняются.

## Разработка

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m compileall -q hey_gpt tests scripts
.venv/Scripts/python.exe -m hey_gpt.model_setup
.venv/Scripts/python.exe scripts/validate_local_speech.py
./scripts/build_windows.ps1
```

`--replay` у GUI и `--wav` у речевого процесса предназначены для явного воспроизведения синтетических тестов, не открывают микрофон. `tests/fixtures/chat.html` — локальная имитация интерфейса, не подключённая к ChatGPT. Её результат не выдаётся за проверку настоящего сервиса.

Авторский код проекта — MIT; зависимости и модели сохраняют свои лицензии: [THIRD_PARTY.md](THIRD_PARTY.md). Код из других голосовых помощников не копировался.
