# Hey GPT for Codex — архитектура и проверка

Версия плагина: 0.1.0-beta.2. Отдельное приложение ChatGPT остаётся 0.4.0-beta. Дата: 1 октября 2026 года.

## Реализовано

- Устанавливаемый локальный Windows-плагин: переносимые Agent Plugins manifest + MCP config, совместимые `.codex-plugin/plugin.json` и `.mcp.json`, skill, lifecycle hooks, готовый Windows runtime.
- Семь MCP-инструментов: состояние, подготовка моделей, включение/отключение микрофона, повтор, настройки, короткое ожидание голоса.
- Микрофон включается явно для session_id текущей задачи. Автозапуск сохраняется только для этого адресата; другие задачи не переназначают его автоматически.
- Диктовка русская или английская, локально Vosk; команда запуска/завершения распознаётся отдельной ограниченной грамматикой. Граница Stop выделяется по временам слов, поэтому искажённое написание команды в свободной диктовке не отправляется в чат.
- Stop получает last_assistant_message непосредственно от Codex. Сводка и полные вопросы извлекаются существующим авторским модулем briefing. Ни экран, ни clipboard, ни файл транскрипта для этого не читаются.
- SAPI озвучивает текст буквально (IsNotXML), с отменой и защитой от попадания собственного голоса в команды.
- Новая голосовая реплика возвращается через документированный Stop decision:block/reason; Codex создаёт продолжение в той же задаче. Молчание никогда не генерирует пустое продолжение.
- Нормальное закрытие сеанса, отключение режима, новая печатная реплика и Ctrl+Alt+P отменяют накопленную диктовку. При исчезновении процесса Codex микрофон закрывается.
- Аутентифицированный Windows named pipe объединяет короткие hooks и MCP со службой, без TCP-порта. Один именованный mutex предотвращает двойное открытие микрофона.

## Границы

Установка проверена на Codex CLI 0.159.2. Его загрузчик пропускает lifecycle hooks для корневого Agent Plugins manifest, хотя документация уже описывает их поддержку. Поэтому Install.cmd сохраняет переносимый manifest как `plugin.portable.json` в установленной копии и выбирает `.codex-plugin/plugin.json`. MCP-путь устанавливается абсолютным в собственной папке версии; cache Codex напрямую не редактируется. Переносимый исходный пакет сохраняет канонические `plugin.json` и `mcp.json`. Для действующей установки нужен Install.cmd из Windows ZIP, а не установка исходников напрямую из GitHub.

Stop синхронно ждёт до 3500 секунд. Это позволяет ответить голосом после результата, но задача может оставаться в состоянии работающего обработчика. После таймаута нужен новый явный запуск ожидания.

SessionStart может автоматически открыть микрофон, однако не создаёт новый ход. Поэтому сценарий «открыла завершённую задачу и сразу голосом запустила новую работу» без активного Stop/voice_wait пока не реализован. На этом компьютере `codex app-server proxy` и `daemon version` не подключились к локальному control socket (Windows os error 10050). Не используется обход через UI-клики, отдельный второй агент или изменение политик безопасности.

Работает только в локальных Codex-задачах Windows. Облачные задачи и web/mobile не поддерживаются. Структурированные формы и разрешения автоматически не подтверждаются. Нет идентификации говорящего; чужая речь и аудиозаписи — риск ложного управления. Малая модель может ошибаться в свободном тексте, даже при достаточной уверенности; это рабочая beta, не гарантия точности.

## Разрешения и данные

Не обходит штатное доверие hooks. Не меняет approval/sandbox политики, не запускает распознанный текст как shell-код и не извлекает токены авторизации Codex. Первичная установка не включает микрофон.

Настройки и локальный IPC-ключ хранятся в LocalAppData пользователя; аудио, расшифровка и последняя сводка — только в памяти приложения. Переданная голосовая реплика становится обычным сообщением в истории Codex. Речевые модели скачиваются через HTTPS существующим проверяемым установщиком. Сводка не делает отдельного API-запроса; выполнение задач использует обычные лимиты Codex.

## Проверка

- 112 автоматических тестов на Windows: прежние сценарии и новая адресация, два цикла вопрос/ответ, отмена, таймаут, ошибки микрофона, отсутствие пустых продолжений, однократная доставка, MCP cancellation, сохранение цитируемой Stop-команды и выделение командной аудиограницы.
- Настоящий stdio MCP из исходников и готового Windows EXE: initialize, tools/list, voice_status и отказ на неизвестные аргументы. Настоящий IPC между процессами. Настоящий hook-процесс из другого рабочего каталога. Микрофон в этом прогоне выключен.
- Штатная установка через `codex plugin marketplace add` и `codex plugin add`. Настоящий Codex app-server: installed/enabled, skill discovery, пять hooks без ошибок, запуск MCP и все семь инструментов. Ни новая задача, ни ход модели в проверке не создавались. Фактическое доверие обработчикам на этом компьютере — trusted; установщик записей доверия не меняет. Проверка готового EXE отдельно исполняет `commandWindows` из manifest через PowerShell с путём, содержащим пробелы.
- Два последовательных синтетических аудиоцикла через настоящие Vosk-модели и сам новый LocalAudio: Hi GPT → «Для разработчиков. Добавь ограничения» → Stop GPT. Получено «для разработчиков добавь ограничения», команды удалены; два разных sequence без повторной доставки. Физический микрофон заменён PCM-fixture.
- Упаковка включает скрытые manifests, готовый EXE и библиотеки, документы и лицензии; исключает аудиофайлы, настройки и IPC-ключ.

Открытая приёмка: доверие hooks человеком; полный живой цикл в официальном интерфейсе Codex с физическим микрофоном, озвучкой, настоящим ответом и новым голосовым сообщением. Синтетические и протокольные проверки не выдаются за эту приёмку.
