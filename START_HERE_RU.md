# Запуск Hey GPT на Windows

Это ранний прототип голосового управления диктовкой в текущем чате ChatGPT или Codex.

1. Установи Python 3.12 с Tkinter и Python Launcher, если их ещё нет.
2. Запусти `Run.cmd` из полностью распакованной папки проекта. При первом запуске он создаст `.venv` и установит зависимости.
3. Для команд нужен английский движок распознавания **System.Speech**. Проверить доступные движки можно в Windows PowerShell:

```powershell
Add-Type -AssemblyName System.Speech
[System.Speech.Recognition.SpeechRecognitionEngine]::InstalledRecognizers() | Select-Object Name, Culture
```

Если список пуст или в нём нет английского языка, голосовые команды пока работать не будут. Наличие Windows Voice Access само по себе не подтверждает наличие движка System.Speech.

4. Открой нужный чат. В Hey GPT нажми **Bind/rebind chat window**, затем за четыре секунды наведи курсор на окно чата.
5. Так же настрой **Message field**, **Dictation microphone**, **Finish recording** и **Send message**. Для кнопки окончания записи начни короткую диктовку вручную; для кнопки отправки подготовь черновик. Затем закончи запись и очисти черновик.
6. Оставь автоматическую отправку выключенной, нажми **Enable listening** и вернись в выбранный чат.
7. Скажи **Hi ChatGPT**, дождись сигнала, продиктуй сообщение и скажи **Stop GPT**. Проверь результат вручную.

**Ctrl+Alt+P** приостанавливает прослушивание помощника. Запись, уже начатую в ChatGPT, нужно закончить или отменить отдельно.

Тесты контроллера и проверка компиляции речевого моста не заменяют проверку микрофона и кнопок в реальном чате. Подробности: [README.md](README.md), [docs/WINDOWS_VALIDATION.md](docs/WINDOWS_VALIDATION.md).
