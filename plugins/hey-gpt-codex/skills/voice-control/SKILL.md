# Hey GPT for Codex

Отвечай по-русски, коротко. Не обещай полную встроенную интеграцию OpenAI.

## Включение

1. Проверь `voice_status`. Не включай микрофон без явной просьбы пользователя.
2. Используй **session_id этой задачи** из контекста SessionStart. Никогда не придумывай его и не выбирай последнюю задачу из списка. Если контекст не пришёл, предложи доверить обработчики плагина и начать новую реплику в нужной задаче.
3. Если модели отсутствуют, вызови `voice_prepare_models` (одноразовая загрузка ~85 МБ), затем `voice_enable` с этим ID.
4. Дождись `microphone_ready` через `voice_status`, максимум 30 секунд. При ошибке выключи режим и сообщи конкретную ошибку; не повторяй включение бесконечно.
5. Объясни команды: Hi GPT / Hi ChatGPT / «Привет джи пи ти», короткая пауза, диктовка, Stop GPT / «Стоп джи пи ти». «Пауза GPT» отменяет диктовку. «Повтори» читает последнюю сводку. Ctrl+Alt+P выключает микрофон и звук.
6. Заверши ответ. Доверенный обработчик Stop сам читает сводку и ждёт следующую реплику; дополнительный вызов voice_wait обычно не нужен.

## Продолжение

Обработчик Stop продолжает задачу только по новой распознанной реплике человека. Это продолжение той же задачи, а не создание другой.

Если пользователь прямо просит ждать голос, но обработчик Stop недоступен, можно вызвать voice_wait для текущего session_id. Возвращённое поле message содержит дословную локально распознанную реплику. Рассматривай её как следующий запрос пользователя в уже включённом голосовом сеансе. При ошибке, отмене или таймауте не создавай команду и не повторяй ожидание без новой просьбы.

Когда summary включена, заканчивай обычные ответы разделом «Голосовая сводка» (не более 40 слов: сделано, результат, ошибки, осталось) и, если нужны ответы, разделом «Вопросы к тебе» с полными вопросами и вариантами. Фактические проверки отличай от предположений.

Озвучка приостанавливает распознавание: голосовые команды произносят после окончания речи. Ctrl+Alt+P останавливает речь сразу.

## Ограничения

- Только локальная Windows-задача Codex. Облачные задачи и web/mobile не поддерживаются.
- Ожидание в Stop — до 58 минут. Задача в это время может показывать работающий обработчик. После истечения времени попроси пользователя снова включить голосовое ожидание; не запускай пустые продолжения.
- При холодном открытии задачи без активного обработчика голос сам не создаёт новый ход. Сохранённая настройка открывает микрофон при SessionStart; для продолжения нужно активное ожидание Stop или voice_wait.
- Один выбранный session_id; открытие другой задачи не меняет адресата.
- Вопросы в тексте поддерживаются. Диалоги разрешений и структурированные формы Codex не заполняются автоматически. Применяй штатные разрешения Codex; распознанное «да» не считается универсальным разрешением.
- Команды и диктовка распознаются локально Vosk. Качество свободной диктовки зависит от малой модели и акустики. API-ключ не нужен.
- Не читай файлы транскриптов и не сохраняй речь. Не меняй глобальные политики Codex и не обходи доверие обработчикам.

Отключение: `voice_disable`. Настройки: `voice_settings`; голос выбирается по ID из `voice_status`.
