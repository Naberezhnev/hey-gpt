# Hey GPT for Codex — 0.1.0 beta.2

Локальный Windows-плагин для голосового продолжения **одной выбранной задачи Codex**. Отдельное окно Hey GPT не открывается. Это независимый экспериментальный модуль, не официальный продукт OpenAI.

## Установка

1. Распакуй **весь** `Hey_GPT_Codex_Plugin_v0_1_0_Windows.zip`.
2. Закрой старое отдельное приложение Hey GPT, чтобы два помощника не слушали одновременно.
3. Запусти `Install.cmd` из папки `hey-gpt-codex`. Установщик копирует модуль в `%LOCALAPPDATA%/HeyGPT/CodexPlugin` и регистрирует его штатными командами Codex. Python не нужен. Права администратора не нужны. При повторной установке той же версии сначала закрой Codex, чтобы он освободил файлы плагина.
4. Перезапусти Codex. Найди **Hey GPT for Codex** в локальном источнике **Hey GPT local**.
5. Проверь и доверь обработчики плагина в браузере обработчиков Codex (`/hooks` в CLI). Это требование Codex: установка плагина сама по себе не доверяет его коду. Установщик не обходит этот шаг.
6. В нужной задаче напиши: **«Включи Hey GPT для этой задачи»**. Модели команд и диктовки загружаются один раз (~85 МБ); ранее установленные Hey GPT модели используются повторно.

Привязка к выбранной задаче сохраняется. Другие открытые задачи не становятся адресатами автоматически.

## Голосовой цикл

После ответа Codex модуль читает краткую сводку и вопросы. Затем:

**Hi GPT / Hi ChatGPT / «Привет джи пи ти» → короткий сигнал → диктовка → Stop GPT / «Стоп джи пи ти».**

После команды запуска и перед командой завершения делай короткую паузу. Сообщение распознаётся локально Vosk и возвращается в ту же задачу через документированный обработчик Stop. Не нужно искать поле сообщения или кнопки браузера. По умолчанию язык свободной диктовки — русский; английский выбирается отдельно.

- **«Повтори»** — повторить последнюю сводку, не выполняя задачу снова.
- **«Пауза джи пи ти»** — отменить текущую диктовку без отправки; последующий Hi GPT снова начинает запись.
- **Ctrl+Alt+P** — выключить микрофон и озвучку, отменить отправку и отключить автозапуск.
- **«Выключи Hey GPT»** в чате — штатное полное отключение.
- Во время озвучки команды не распознаются. Произноси их после окончания речи; Ctrl+Alt+P работает и во время озвучки.

Скажи Codex «покажи состояние Hey GPT», чтобы увидеть включён ли микрофон, готов ли он и есть ли активное ожидание реплики. Установленные голоса Windows доступны через voice_status; сводка, автозапуск и язык — через voice_settings.

## Честные границы этой версии

- Поддерживаются **локальные Windows-задачи Codex**. Cloud, браузерный ChatGPT, web/mobile и другие ОС этой сборкой не обслуживаются.
- Обработчик Stop ждёт новую реплику до **3500 секунд (58 минут 20 секунд)**. Codex может показывать задачу как работающую, пока ожидается голос. Молчание не создаёт новые запросы к модели.
- После истечения времени попроси в чате снова ждать голос. Обычный voice_wait ждёт до 50 секунд и укладывается в стандартный таймаут MCP; следующие ответы снова используют длинное ожидание Stop.
- **Холодное открытие завершённой задачи без активного ожидания не запускает новый ход голосом.** Автозапуск по SessionStart открывает микрофон для ранее выбранной задачи, но сам этот обработчик не создаёт ход. Полностью постоянный вызов из любого состояния официального приложения пока не реализован.
- Не предусмотрено одновременное управление несколькими задачами. Сначала выключи режим в одной и явно включи в другой.
- Качество малой локальной модели диктовки может быть ниже серверной диктовки ChatGPT. Неуверенные, пустые, слишком длинные сообщения не отправляются. Диктовка ограничена двумя минутами.
- Вопросы в тексте читаются; диалоги разрешений и структурированные формы Codex автоматически не заполняются и не подтверждаются.
- Нет распознавания владельца по голосу: другие люди и записи могут произнести команды. Используй гарнитуру и включай микрофон, когда действительно работаешь голосом.
- Проверка аппаратного полного цикла в интерфейсе Codex требует доверия обработчикам и отдельного живого прогона. Автоматические проверки сами по себе не заменяют этот прогон.

## Данные и разрешения

Плагин использует микрофон и установленный голос Windows. Аудио и расшифровки не сохраняет; последний результат хранится в памяти. Распознанная реплика становится обычным сообщением задачи Codex и хранится самим Codex по его настройкам. Сводка основана на фактическом тексте ответа; если специального раздела нет, читается обозначенный фрагмент.

В `%LOCALAPPDATA%/HeyGPT/codex` сохраняются настройки и случайный ключ локального IPC. Это Windows named pipe с аутентификацией; сетевого порта нет. API-ключ OpenAI не нужен, отдельного API-запроса для сводки нет. Работа Codex использует его обычную авторизацию и лимиты.

Удаление: сначала выключи Hey GPT, затем удали плагин в Codex или командой `codex plugin remove hey-gpt-codex@hey-gpt-local`. Установщик не меняет политики безопасности Codex и не выдаёт разрешения задачам.
